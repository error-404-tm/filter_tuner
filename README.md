# filter_tuner

An interactive pole/zero filter designer. Place and drag zeros and poles on the
z-plane and watch the magnitude, phase, group delay, and impulse/step responses
update live. Then take the design to hardware: quantize it to fixed point, check
headroom, and export CMSIS-DSP C or a synthesizable Verilog biquad cascade with
a bit-exact testbench.

## Running

```bash
pip install -r requirements.txt
python -m filter_tuner            # or: python multipole_filter_lab.py
python -m filter_tuner my.json    # open a saved project
```

`pip install -e .` also installs a `filter-tuner` command.

## Editing on the z-plane

| Action | Effect |
|---|---|
| Click empty space | Add a conjugate pair (zero or pole, by mode) |
| Shift-click | Add a single real root |
| Drag a root | Move it; the conjugate follows. Hold **Shift** for 10× finer motion |
| Right-click a root | Delete it |
| `Z` / `P` | Clicking adds zeros / poles |
| `S` / `A` | Select next / previous root |
| `Delete` | Delete the selected root |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / redo (a whole drag is one step) |
| `L` / `H` / `C` / `R` | Log frequency axis / \|H(z)\| landscape / snap to unit circle / snap to real axis |

The **Roots** panel edits the selected root numerically: radius, `1 − r` (for
fine control right next to the unit circle), angle, or real/imag.

## Panels

- **Filter**: sample rate (all frequencies are in its units; 1.0 = cycles/sample)
  and gain normalization: manual k, or 0 dB at DC, Nyquist, the peak, or a chosen
  frequency.
- **Design**: seed from Butterworth / Chebyshev I/II / elliptic / Bessel, or an FIR
  (`firwin`, `remez`), then hand-tune. The old design comes back with undo.
- **Mask**: passband/stopband limits drawn on the magnitude plot; violations
  are marked. **Fit current design to mask** runs a bounded optimizer from your
  placement (poles kept under a max radius) and is a single undo step.
- **Fixed-point**: coefficient word/fraction bits, data width, and L∞/L2 section
  scaling. Shows quantized poles/zeros on the z-plane and the quantized response
  as a dashed curve, plus saturation, quantized stability, per-section headroom
  and the integer coefficients.
- **Export**: CMSIS-DSP `arm_biquad_cascade_df2T_f32`, `df1_q31`, and `df1_q15`
  init code (with CMSIS's negated feedback signs), or a Verilog bundle:
  `biquad_df1.v`, the cascade top, `coeffs.mem`, and a self-checking testbench
  with `stimulus.mem`/`expected.mem` generated by the bit-accurate Python model.
- **Math**: factored H(z), expanded polynomials, SOS matrix, LaTeX.
- **Signal**: load WAV/CSV/NPY (CSV: last column is the signal), filter it with the
  float or quantized design (optionally zero-phase), and compare spectrograms.

Projects (filter, mask, fixed-point settings) save as JSON from the File menu.

## Layout

```
filter_tuner/
  model.py         Root / GainSpec / FilterState (immutable)
  dsp.py           analysis from ZPK + SOS (no high-order polynomials)
  observable.py    Observable + undoable variant (gestures, coalescing)
  session.py       app state + derived analysis/fixed-point results (Qt-free)
  design.py        classical IIR/FIR seeds
  mask.py          spec masks
  optimize.py      mask fitting
  quantize.py      fixed-point formats, scaling, bit-accurate DF-I model
  export/          cmsis.py, verilog.py
  formatting.py    transfer-function text/LaTeX
  signal_io.py     signal loading, filtering, spectrograms
  project_io.py    JSON save/load
  ui/              Qt widgets; each panel talks only to the Session
```

Everything outside `ui/` is Qt-free and covered by `pytest`. If `yowasp-yosys` and
`g++` are installed, the tests also compile the generated Verilog with Yosys's
CXXRTL backend and check it is bit-exact against the Python model.
